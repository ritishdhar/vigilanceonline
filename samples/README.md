# Test videos

Supplied demo clips are bundled with the Git repository. Add an
approved MP4, WebM, MOV, AVI, MKV or other supported video file here for local
testing; reload the dashboard to expand the test-video bar. Share only videos
you have permission to distribute. No camera recordings are saved here. Only
files directly inside this directory are served; links and nested paths are
excluded. The frontend never receives arbitrary filesystem access.
